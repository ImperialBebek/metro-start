# Changelog

## 1.11.1
- Store-ready icon (96×96 artwork with transparent padding) and updated description.

## 1.11.0
- Windows 8 parallax: the wallpaper slides more slowly than the tiles as you scroll. Can be turned off in Personalize.

## 1.10.0
- Wallpaper gallery with Landscapes, Seascapes, Cities, Night sky and Paintings from Wikimedia Commons Featured Pictures. Picks are saved locally and credited on screen.

## 1.9.0
- New games: Five Letters (daily word game with practice words), Snake, Blocks and Bricks.

## 1.8.1
- Flipping tiles on open is now off by default.

## 1.8.0
- Games: Solitaire, Minesweeper, Sudoku (with a daily puzzle) and 2048, with saved progress and best scores.
- Optional flip animation when opening a tile.

## 1.7.0
- Folder tiles have a tab, a folder icon and a chevron so they stand out from sites.
- News and Markets widgets in the bottom bar.
- Bookmark import can erase Start first; import options are stacked.

## 1.6.0
- Nested folders, with a path you can click and Esc to go up a level.

## 1.5.0
- Bookmark import fetches sharp icons from each website, or uses the icon Chrome saved.

## 1.4.x
- Rounded (Nunito) or Metro (Segoe UI) font.
- Weather falls back to an approximate location and explains errors.
- Fixed the icon options in the tile editor.

## 1.3.0
- Removed live tiles.

## 1.1.0
- Import Chrome bookmarks as tiles and folders.

## 1.0.0
- First version: tiles in four sizes, folders, drag and drop, backgrounds, clock and weather, type to search, backup.
